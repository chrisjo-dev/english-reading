방문 통계

방문 수, 유입 경로, 페이지 이용 흐름, 버튼 사용(주제 반응, 단어 외우기, 의견 보내기 등)을 익명 통계로 봐요. IP 주소는 익명 처리하고 이름이나 이메일과 연결하지 않아요.

맡긴 곳: Google Analytics 4, Microsoft Clarity

광고

Google AdSense 광고를 보여 줄 수 있어요. 아래 3번을 봐 주세요.

맡긴 곳: Google AdSense

의견 메일

기능 건의나 버그 제보 버튼은 메일 앱을 열어요. 버그 제보에는 누른 페이지 주소, 기기와 브라우저 이름, 화면 크기가 미리 채워지고, 보내기 전에 지울 수 있어요. 받은 메일은 답장과 수정에만 써요.

접속 기록

사이트는 GitHub Pages로 제공돼요. GitHub는 보안과 운영을 위해 접속 IP 등을 기록할 수 있어요. 글꼴(cdnjs)을 불러올 때도 그 제공자에게 접속 정보가 전달될 수 있어요.

제공: GitHub Pages, cdnjs

2브라우저에 저장하는 값

학습 기록과 설정은 이용자 기기의 브라우저 저장소(localStorage)에만 두고, 독해한입 서버로 보내지 않아요. 브라우저 사이트 데이터를 지우면 함께 사라져요.

  • drill:v1단어 외우기 복습 기록(다시 물을 날짜)
  • drill:pref단어 외우기 방식(카드, 문제)
  • read_level:언어언어별로 고른 지문 수준
  • read_speed음성 재생 속도
  • vote:언어/날짜오늘 주제 반응(좋아요, 별로예요). 반응 자체는 방문 통계로도 보내요
  • lily.justListen릴리 그림책 듣기 페이지의 '듣기만' 설정

3쿠키와 광고

Google을 포함한 제3자 광고 업체는 쿠키를 써서, 이 사이트와 다른 사이트를 방문한 기록을 바탕으로 광고를 보여 줄 수 있어요. 자세한 내용은 Google 파트너 사이트의 데이터 사용 방식에 있어요.

맞춤 광고는 Google 광고 설정에서, 제3자 업체 맞춤 광고 쿠키는 www.aboutads.info에서 끌 수 있어요. Google Analytics 수집은 수집 거부 부가 기능으로 막을 수 있어요. 쿠키를 거부해도 읽기에는 문제가 없어요.
