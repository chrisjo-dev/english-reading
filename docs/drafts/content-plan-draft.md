# 지문 개선 초안 검토 (이슈 #25)

공통 규칙은 `tools/ROUTINE.common.md`, 문법 목록은 `tools/grammar/`에 있다. 아직 예약 작업에 연결하지 않았다.

## 요일표 변경

유형은 확정안이고, 언어별 분야는 제안이다.

| 요일 | 유형 | 영어 현재 → 변경 | 일본어 현재 → 변경 | 독일어 현재 → 변경 |
|---|---|---|---|---|
| 월 | 소식 | 과학 뉴스 → 과학, 우주 소식 | 생활, 일기 → 생활, 지역 소식 | 일상생활 → 교통, 쇼핑, 생활 소식 |
| 화 | 설명 | 기술 원리 → 기술 원리 | 일본 문화 → 일본 문화 | 독일어권 문화 → 독일어권 문화 |
| 수 | 소식 | 사회 현장 → 사회 소식 | 쉬운 뉴스 → 쉬운 뉴스 | 쉬운 뉴스 → 쉬운 뉴스 |
| 목 | 설명 | 미래 찬반 → 건강, 문화 설명 | 일과 학교 대화 → 일과 학교 제도 설명 | 일과 학교 → 일과 학교 제도 설명 |
| 금 | 소식 | 과학 원리 → 기술, 미래 소식 (장점과 우려 함께) | 과학과 자연 → 과학과 자연 소식 | 과학과 자연 → 과학과 자연 소식 |
| 토 | 생활 글 | 일상 문화 현장 → 일상 생활 글 | 여행 안내 → 가상 여행기 | 여행과 장소 → 가상 여행기 |
| 일 | 생활 글 | 우주, 미래 뉴스 → 일과 학교 대화, 경험담 | 계절 이야기 → 계절 생활 글 | 계절과 날씨 → 계절 생활 글 |

## 문법 항목 수

| 언어 | 기초 a | 중급 b |

측정에서 빠졌던 문법(영어 현재완료, will, be going to, if 조건문, 독일어 Perfekt, Präteritum, Futur, 일본어 예정, 가능, 조건)은 모두 들어 있다.

자동 점검이 되는 항목은 `pattern`이 있는 것뿐이다. 최근 30일 지문의 절반 이상에 걸릴 만큼 넓은 패턴은 `null`로 두었다(영어 6, 일본어 4, 독일어 4). 사용 기록은 `grammar`의 `id`로 하므로 배정에는 영향이 없다.

## 반영 순서

아래를 한 번에 반영한다. 스크립트가 완성되기 전에는 예약 작업에 연결하지 않는다.

1. 문법 후보 스크립트 구현
2. `check_content.py` 공통 출처 경고: `fit` 기준, 세 언어 적용, 기존 일본어 화수금 경고를 교체
3. 영어 문장 길이 경고 추가
4. 세 언어 루틴 전환: `ROUTINE.common.md`를 읽게 하고 요일표, 약점 표현, 체크 포인트 규칙을 함께 변경

## 반영 뒤 확인

- 독일어 출처 필수일이 주 1일에서 5일로 늘어난다. 일본어와 영어도 함께 첫 2주 동안 출처 성공률을 확인한다.
- 첫 2주의 `grammar` 빈 목록 비율을 확인한다.

## 후속

- 비축분(`pool`)에 `fit`을 넣는 일은 이번 범위에서 뺀 선택 개선이다.

## 판단이 필요한 점

1. **영어 중급 문장 길이**: 12~26단어를 제안한다. B2 표시 문장만 30단어까지 허용한다. 지금은 규칙이 없고 최근 14일 중앙값 25단어, 최대 42단어다.
2. **언어별 분야**: 위 표의 분야 배정이 맞는지.
3. **비축분(`pool`)**: 비상 발행용 지문은 이 구조를 따르지 않고 지금 그대로 두는 안을 제안한다.
4. **범위 상단 문법**: 영어 `b-third-conditional`, 독일어 `b-konjunktiv-i`는 범위 상단이라 빈도를 낮춰도 된다.
