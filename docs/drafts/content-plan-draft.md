## 요일표 변경

유형은 확정안이고, 언어별 분야는 제안이다.

| 요일 | 유형 | 영어 현재 → 변경 | 일본어 현재 → 변경 | 독일어 현재 → 변경 |
|---|---|---|---|---|
| 월 | 소식 | 과학 뉴스 → 과학, 우주 소식 | 생활, 일기 → 생활, 지역 소식 | 일상생활 → 교통, 쇼핑, 생활 소식 |
| 화 | 설명 | 기술 원리 → 기술 원리 | 일본 문화 → 일본 문화 | 독일어권 문화 → 독일어권 문화 |
| 수 | 소식 | 사회 현장 → 사회 소식 | 쉬운 뉴스 → 쉬운 뉴스 | 쉬운 뉴스 → 쉬운 뉴스 |
| 목 | 설명 | 미래 찬반 → 건강, 문화 설명 | 일과 학교 대화 → 일과 학교 제도 설명 | 일과 학교 → 일과 학교 제도 설명 |
| 금 | 소식 | 과학 원리 → 기술, 미래 소식 (장점과 우려 함께) | 과학과 자연 → 과학과 자연 소식 | 과학과 자연 → 과학과 자연 소식 |
| 토 | 생활 글 | 일상 문화 현장 → 일상 생활 글 | 여행 안내 → 가상 여행기 | 여행과 장소 → 가상 여행기 |

## 판단이 필요한 점

1. **영어 중급 문장 길이**: 12~26단어를 제안한다. B2 표시 문장만 30단어까지 허용한다. 지금은 규칙이 없고 최근 14일 중앙값 25단어, 최대 42단어다.
2. **언어별 분야**: 위 표의 분야 배정이 맞는지.
3. **비축분(`pool`)**: 비상 발행용 지문은 이 구조를 따르지 않고 지금 그대로 두는 안을 제안한다.
4. **범위 상단 문법**: 영어 `b-third-conditional`, 독일어 `b-konjunktiv-i`는 범위 상단이라 빈도를 낮춰도 된다.
